# Video Editing Platform (Frontend)

## 📌 Project Overview
This is the frontend for a browser-based video editing tool. It allows users to upload, trim, rearrange, and overlay subtitles/text/images on videos. The project is built using **Next.js, React.js, Tailwind CSS, Redux Toolkit**, and **ShadCN UI** for components.

## 🚀 Features
- **Video Upload:** Drag-and-drop upload with preview and progress indicator.
- **Editing Timeline:** Scene trimming, drag-and-drop rearrangement.
- **Audio Management:** Mute, rearrange, and add background audio.
- **Text & Subtitle Overlay:** Customize font, size, color, and position.
- **Image Overlay:** Upload, resize, and position images.
- **Real-time Preview & Export:** Live preview and mock rendering/download options.

## 💻 Tech Stack
- **Framework:** Next.js (App Router)
- **Frontend:** React.js, Tailwind CSS, ShadCN UI
- **State Management:** Redux Toolkit
- **Additional Libraries:** React Player, React Dropzone, React DnD
